# Multiplayer Overview

BNOS uses visibility scopes so the same gameplay event can be presented differently to different players.

The three scopes are:

* **Local**, player-specific
* **Team**, shared with eligible team members
* **Global**, shared globally with eligible players

Team and Global shared state is managed through the World Manager.

Test multiplayer behaviour using the network mode appropriate to your project, including multiple PIE players and your intended server model.
