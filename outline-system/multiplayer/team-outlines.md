# Team Outlines

Team outlines are intended for information shared with eligible members of a team.

## Setup

1. Create the required Team Gameplay Tags.
2. Assign the correct Team Tag to each player's Outline Component.
3. Create a preset using **Team** Visibility Mode.
4. Register that preset in the active Preset Library.
5. Apply it through the normal Outline Component API.

Example team tags:

```text
BNOS.Team.Blue
BNOS.Team.Red
```

Use `SetTeamTag` if a player's team changes at runtime.
