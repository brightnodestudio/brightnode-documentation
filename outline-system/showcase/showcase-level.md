# Showcase Level

The included showcase level demonstrates the major BNOS features and provides working examples that can be inspected directly in Blueprint.

Use it to review:

* Basic outline application and removal
* Outline colours and thicknesses
* Local, Team, and Global visibility
* Expiry
* Priority
* Flashing
* Mesh selection
* Through-wall behaviour
* Multiplayer-oriented examples

The showcase is example content. Your production gameplay does not need to reproduce its presentation or demonstration logic.
