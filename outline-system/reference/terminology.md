# Terminology

| Term | Meaning |
| --- | --- |
| BNOS | Brightnode Outline System |
| Outline Component | Player-side component providing the main gameplay API |
| World Manager | Manager responsible for shared Team and Global outline state |
| Outline Preset | Data Asset defining an outline's behaviour |
| Preset Library | Collection of presets available to BNOS |
| Preset Tag | Gameplay Tag identifying an Outline Preset |
| Team Tag | Gameplay Tag identifying a player's team |
| Visibility Mode | Local, Team, or Global visibility scope |
| Priority | Value used to resolve competing requests |
| Required Mesh Tags | Component Tags used for mesh filtering |
| Outline Handle | Identifier associated with an active outline request |
