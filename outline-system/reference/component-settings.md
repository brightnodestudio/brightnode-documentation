# Component Settings Reference

| Setting | Description |
| --- | --- |
| Outline Post Process Material | Post Process material used to render outlines |
| Flash Tick Rate | Time between flash processing updates |
| Through Wall Outlines Enabled | Determines whether outlines can render through occluding geometry |
| Auto Initialize | Automatically initializes the component at play start |
| Team Tag | Gameplay Tag identifying the player's team |
| Show Debug | Enables runtime component debug output |
