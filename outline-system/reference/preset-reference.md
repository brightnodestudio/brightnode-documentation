# Preset Reference

| Category | Setting | Description |
| --- | --- | --- |
| Identity | Preset Tag | Gameplay Tag uniquely identifying the preset |
| Identity | Visibility Mode | Determines Local, Team, or Global visibility |
| Lifetime | Has Expiry | Enables automatic expiry |
| Lifetime | Expiry Duration | Time before the request expires |
| Priority | Priority | Resolves competing requests, higher values take precedence |
| Outline Visuals | Outline Colour | Selects the outline colour preset |
| Outline Visuals | Outline Thickness | Selects the outline thickness preset |
| Mesh Selection | Mesh Selection Mode | Determines which mesh components are affected |
| Mesh Selection | Required Mesh Tags | Component Tags used by tag-based mesh selection |
| Flashing | Start Flashing | Starts flashing when applied |
| Flashing | Flash On Duration | Visible duration per flash cycle |
| Flashing | Flash Off Duration | Hidden duration per flash cycle |
| Flashing | Randomise Flash Start | Randomises initial flash timing |
| Flashing | Flash Start Random Range | Controls the random initial delay |
