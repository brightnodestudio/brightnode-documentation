# Through-Wall Outlines

BNOS can control whether outlines are visible through occluding world geometry.

The default behaviour is configured on the player's Outline Component.

At runtime use:

```
SetThroughWallOutlinesEnabled
```

<figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>

This is useful for detection modes, tactical vision, scans, accessibility options, and other gameplay states where through-wall visibility changes dynamically.
