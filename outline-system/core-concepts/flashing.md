# Flashing

Outline Presets can begin flashing automatically when applied.

## Start Flashing

Enables flashing for the preset.

## Flash On Duration

Time the outline remains visible during each cycle.

## Flash Off Duration

Time the outline remains hidden during each cycle.

## Randomise Flash Start

Randomises the initial start time. This is useful when many actors use the same flashing preset.

## Flash Start Random Range

Controls the random delay used before flashing begins.

The Outline Component's **Flash Tick Rate** controls processing frequency. The preset durations control the intended visual rhythm.
