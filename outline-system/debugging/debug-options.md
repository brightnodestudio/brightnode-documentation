# Debug Options

Both major runtime components expose a **Show Debug** option.

## Outline Component

Use component debug output when investigating:

* Local processing
* Player configuration
* Team configuration
* Application and removal behaviour
* Player-side outline state

## World Manager

Use World Manager debug output when investigating:

* Team state
* Global state
* Shared runtime processing
* Manager requests

Disable debug output for normal gameplay unless intentionally required.
