# Preset Library

The Outline Preset Library registers the Outline Preset Data Assets available to BNOS.

## Library Name

Optional identifier for the library.

## Outline Presets

Array containing the Outline Preset Data Assets registered with the library.

To make a new preset available:

1. Create its Gameplay Tag.
2. Create the Outline Preset.
3. Assign the Gameplay Tag to **Preset Tag**.
4. Add the preset to **Outline Presets**.
5. Ensure this library is assigned to the World Manager.
