# Brightnode Outline System

Version 1.0.0 | Unreal Engine 5.5+ | Pure Blueprint

Welcome to the official documentation for the Brightnode Outline System, a data-driven, multiplayer-ready outline framework built entirely in Blueprint for Unreal Engine 5.

***

## What Is It?

The Outline System provides a reusable framework for applying and managing gameplay outlines without tying visual logic directly to your interaction, targeting, AI, objective, or ability systems.

Outline behaviour is defined through Data Assets and Gameplay Tags. Presets control visibility, lifetime, priority, appearance, mesh selection, and flashing, while the runtime system handles Local, Team, and Global presentation.

***

## Key Features

* Pure Blueprint, no C++ required
* Data Driven, reusable Outline Preset Data Assets
* Gameplay Tag based preset identification
* Multiplayer Ready, Local, Team, and Global visibility modes
* Priority System, resolves competing outline requests
* Timed Outlines, optional automatic expiry
* Flashing, configurable on/off duration and randomised start
* Mesh Selection, whole actor or component-tag based selection
* Through Wall Control, configurable per player
* Blueprint API, simple gameplay-facing component interface
* Debug Tools, component and World Manager debug output
* Showcase Level, working examples of the major features
