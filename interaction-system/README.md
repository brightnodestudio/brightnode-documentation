# Brightnode Interaction System

**Version 2.0.0 | Unreal Engine 5.5+ | Pure Blueprint**

Welcome to the official documentation for the Brightnode Interaction System, a data-driven, multiplayer-ready interaction framework built entirely in Blueprint for Unreal Engine 5.

#### What Is It?

The Interaction System provides a reusable framework for detecting, presenting, and executing player interactions without tying interaction logic directly to your characters, actors, UI, or gameplay systems.

Interaction behaviour is defined through reusable Data Assets, while the runtime system handles focus detection, interaction state, prompts, sustained interactions, locking, grabbing, and multiplayer execution.

***

#### Key Features

* Pure Blueprint, no C++ required
* Data Driven, reusable Interaction Definition Data Assets
* Multiple Interaction Types, Press, Hold To Complete, While Holding, and Grab
* Multiplayer Ready, server-authoritative interaction execution
* Focus Detection, configurable trace and detection behaviour
* Interaction Prompts, configurable input-aware player feedback
* Interaction States, centralised runtime interaction state
* Interaction Locking, control access to interactable actors
* Sustained Interactions, configurable progress and cancellation behaviour
* Grab Interactions, built-in support for object manipulation
* Blueprint API, simple gameplay-facing component interface
* Debug Tools, runtime focus and interaction debugging
* Showcase Level, working examples of the major features

#### Requirements

| Requirement      | Detail                     |
| ---------------- | -------------------------- |
| Engine Version   | Unreal Engine 5.5+         |
| Implementation   | Pure Blueprint             |
| Plugins Required | Common UI                  |
| Multiplayer      | Full replication supported |
| C++              | Not Required               |
