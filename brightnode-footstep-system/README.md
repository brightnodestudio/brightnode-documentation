# Brightnode Footstep System

**Version 1.0.0 | Unreal Engine 5.5+ | Blueprint & C++ Plugin**

The Brightnode Dynamic Footstep System is a multiplayer-ready, surface-aware footstep framework for Unreal Engine 5. Configure surface-specific sounds, Niagara effects and footprint decals through data assets, add the component to your character, and generate dynamic footsteps with support for full-body animation notifies and first-person timer-based movement.

The system includes a custom Animation Modifier for automatically generating footstep notifies, movement-specific effects, AI noise integration and replicated footstep playback.

### Key Features

* **Surface aware**, automatically detects Physical Materials and selects the appropriate footstep effects
* **Data driven**, configure sounds, Niagara effects and footprint decals through reusable Footstep Profile data assets
* **Movement based**, individual configurations for walking, running, sprinting, crouching, jumping and landing
* **Automatic animation notifies**, generate left and right footstep notifies using the included C++ Animation Modifier
* **First-person and third-person**, supports full-body animation notifies and timer-based footsteps for arms-only characters
* **Niagara and decals**, surface-specific particle effects, left and right footprints, and decal fading
* **Multiplayer ready**, server-side processing with multicast playback and distance filtering
* **AI hearing**, integrated footstep noise events for use with AI perception systems
