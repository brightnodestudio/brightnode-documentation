# Changelog

### Version 1.0.0

**Initial Release, Draft**

#### Core System

* Modular Footstep System component
* Data-driven Footstep Profiles
* Physical Material surface detection
* Movement-specific footstep events
* Support for first-person and third-person characters

#### Animation

* C++ automatic footstep Animation Modifier
* Left and right foot contact detection
* Configurable sampling and speed thresholds
* Animation Notify-based footsteps
* Timer-based first-person footsteps

#### Audio & Effects

* Surface-specific footstep sounds
* Multiple audio variations
* MetaSound support
* Niagara particle effects
* Left and right footprint decals
* Decal lifetime and fading
* Jump and landing feedback

#### Multiplayer

* Server-side footstep processing
* Multicast remote footsteps
* Local effect playback
* Remote distance filtering
* AI noise processing
