# Automatic Animation Notifies

The Brightnode Dynamic Footstep System includes a custom C++ Animation Modifier that automatically generates footstep notifies based on foot bone movement.

This removes the need to manually place every footstep notify across your locomotion animations.

### How It Works

The Animation Modifier samples selected foot bones throughout an Animation Sequence.

Using the configured movement speed threshold, it identifies potential foot contact events and generates the appropriate left or right footstep notify.

The modifier also avoids generating a notify simply because a foot begins the animation in a planted position.

### Applying the Modifier

1. Open an Animation Sequence.
2. Locate the Animation Data Modifiers section.
3. Add the supplied Auto Generate Footstep Notifies modifier.
4. Configure the foot bones and their corresponding sides.
5. Select the footstep notify class.
6. Configure the detection settings.
7. Apply the modifier.
8. Review the generated notifies.

### Modifier Settings

| Setting               | Description                                      |
| --------------------- | ------------------------------------------------ |
| Sample Rate           | Frequency used to analyse foot bone movement     |
| Speed Threshold       | Movement threshold used to identify foot contact |
| Footstep Notify Class | Notify class generated by the modifier           |
| Feet                  | Array of bones used for footstep detection       |

### Foot Definitions

Each foot definition contains:

| Property       | Description         |
| -------------- | ------------------- |
| Foot Bone Name | Bone to analyse     |
| Foot Side      | Left, Right or None |

Example configuration:

| Foot Bone Name | Foot Side |
| -------------- | --------- |
| foot\_l        | Left      |
| foot\_r        | Right     |

Use the appropriate bone names for your character's skeleton.

### Adjusting Detection

**Sample Rate**

Higher sampling rates provide more detailed motion analysis but require additional processing when applying the modifier.

**Speed Threshold**

Controls how much foot movement is permitted when identifying a potential contact.

If footsteps are being missed or additional footsteps are generated, adjust this threshold and reapply the modifier.

### Important Notes

* The modifier operates on Animation Sequences.
* Generated notifies should be checked before use.
* Animations with unusual foot movement may require manual adjustments.
* The modifier supports looping locomotion animations.
* Generated notifies trigger the Footstep System during gameplay.

The Animation Modifier generates the contact events. The Footstep System handles surface detection and effect playback.
